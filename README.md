# DevTrack

A React + Vite personal developer progress dashboard.

## Features

- Dashboard with progress statistics
- Learning task management
- Project tracking
- Skill progress tracking
- Learning notes
- Dark/light mode
- Search across tasks, projects, skills and notes
- LocalStorage persistence
- Responsive mobile layout

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.
